
# 🛒 Анализ продаж интернет-магазина

**SalesAnalyzer** — это консольное приложение на Python для **анализа продаж интернет-магазина** за выбранный период. Программа позволяет рассчитывать **выручку**, средний чек, медиану, процент возвратов и анализировать продажи по категориям, городам и способам оплаты.

Проект также определяет лучшие и худшие дни продаж и формирует различные статистические показатели.

##  Возможности

- 💰 Расчёт **общей выручки** интернет-магазина.
- 🧾 Расчёт **среднего чека**.
- 📊 Расчёт **медианы суммы заказа**.
- ↩️ Подсчёт количества и доли **возвратов**.
- 🏆 Определение **топ-N товаров** по продажам.
- 📦 Распределение заказов по категориям.
- 🏙️ Анализ продаж по городам.
- 💳 Распределение заказов по способам оплаты.
- 📅 Определение лучшего и худшего дня продаж.
- 📈 Расчёт процентилей суммы заказов.
- 🔎 Фильтрация по категории и минимальной сумме заказа.
- 💱 Масштабирование денежных значений с помощью параметра `currency_scale`.

## Установка

Для работы приложения требуется **Python 3.10 или новее**.

1. Установите Python.
2. Клонируйте репозиторий.
3. Перейдите в папку проекта.
4. Создайте виртуальное окружение.
5. Установите зависимости.

### Команды установки

```bash
git clone https://github.com/user/sales-analyzer.git
cd sales-analyzer
python -m venv venv
pip install -r requirements.txt
```

> ⚠️ **Важно:** если приложение использует только стандартные библиотеки Python, файл `requirements.txt` может не требоваться.

## Использование

Основная функция проекта — `analyze_sales()`.

### Пример вызова

```python
from sales_analyzer import analyze_sales

report = analyze_sales(
    orders=orders,
    start_date="2026-01-01",
    end_date="2026-01-31",
    category_filter=None,
    min_amount=0,
    top_n=5,
    include_returns=True,
    currency_scale=1
)

print(report)
```

### Основные CLI-команды

| Команда | Описание |
|---|---|
| `analyze` | Запустить анализ продаж |
| `--start-date` | Указать начальную дату |
| `--end-date` | Указать конечную дату |
| `--category` | Фильтр по категории |
| `--min-amount` | Минимальная сумма заказа |
| `--top-n` | Количество элементов в топе |
| `--include-returns` | Учитывать возвраты |

## Архитектура

<a id="architecture"></a>

> **SalesAnalyzer** выполняет анализ в несколько этапов: сначала получает исходные заказы, затем применяет фильтры, рассчитывает статистические показатели и формирует итоговый словарь с результатами.

### Схема работы

```text
┌──────────────────────┐
│    Список заказов    │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Фильтрация данных   │
│  • Дата              │
│  • Категория         │
│  • Сумма             │
│  • Возвраты          │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   Анализ продаж      │
│  • Выручка           │
│  • Средний чек       │
│  • Медиана           │
│  • Процентили        │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   Группировка данных │
│  • Категории         │
│  • Города            │
│  • Оплата            │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   Итоговый словарь   │
└──────────────────────┘
```
